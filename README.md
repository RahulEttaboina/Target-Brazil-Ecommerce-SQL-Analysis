# 🛒 Target Brazil E-Commerce SQL Analysis

## 📌 Project Overview

This project analyses the **Target Brazil E-Commerce dataset** using **Google BigQuery SQL** to uncover customer purchasing behavior, payment trends, freight costs, delivery performance, and regional sales patterns.

The objective is to transform raw transactional data into meaningful business insights that support strategic decision-making.

---

## 🎯 Business Problem

Target Brazil aims to understand:

- Customer purchasing patterns
- Order growth over time
- Delivery performance
- Freight costs
- Payment behaviour
- Regional sales distribution

By analysing historical order data, businesses can optimise logistics, improve customer satisfaction, and make data-driven decisions.
